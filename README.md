# Yasser Bin Mahfouz — Portfolio

Responsive Arabic and English portfolio with light and dark themes, project galleries and downloadable CVs.

## Preview

Open `dist/index.html` in a browser. No build or dependencies are required.

## Netlify

Import the GitHub repository into Netlify. `netlify.toml` sets the publish directory to `dist`; leave the build command empty.

## Content

The published files, images and CVs are in `dist/`.
